# GemB Places

A compact list of 236,278 places (population 500 and up) for the GemB AstroSynth Chart block and app.
Each row: name, plain-letter name, country, region code, latitude and longitude (2 decimals), time zone number, alternate spellings for big cities.

Data: GeoNames (https://www.geonames.org), cities500, licensed under Creative Commons Attribution 4.0 (CC BY 4.0).
The data is provided "as is". Compacted by Gemini Brett / Earthstrology.
